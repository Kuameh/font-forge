# ADR-0007 — The specimen is generated from built fonts, not sources

- **Status**: Accepted
- **Date**: 2026-09-23

## Context

Contributors and users need one place to see every family. It could be (a) a framework site (Next.js/Astro) — more power, but a Node toolchain for a page of type testers; (b) a hand-maintained HTML page — goes stale on the first new family; (c) **a static page generated by a script from `fonts/`** — always in sync with what users download, no extra toolchain.

## Decision

`scripts/specimen.py` reads `fonts/*/family.toml` and each variable font, and writes `specimen/index.html` from `scripts/specimen.template.html`. It never reads `sources/`. `make build` runs it; `make serve` serves it.

## Consequences

- The specimen shows exactly the shipped binaries — a broken build shows up as a broken specimen.
- A single-page, plain-JS design limits how rich the specimen can become; a larger site would supersede this ADR.
- `specimen/index.html` is generated and committed alongside `fonts/`; never edit it by hand — edit the template.
